# Cooperative Perception

This directory contains the Docker Compose override and RViz configurations for the cooperative-perception example.

Start the example in one of two ways:

- **Configuration GUI:** Select the `cooperative-perception` preset and start OpenADSim.
- **Docker Compose:** Run the following command from the top-level OpenADSim repository directory:

```bash
docker compose --env-file examples/cooperative-perception/.env up -d
```

The example `.env` contains the complete configuration also generated by the GUI preset. To use the full sensor layout, set `rita-all.json` instead of `rita-minimal.json` in this file.

For requirements, sensor layouts, setup instructions, and background information, see the [Cooperative Perception guide](../../docs/example-cooperative-perception.md).
